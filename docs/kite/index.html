🪁 한국 전통 방패연 완벽 가이드

과학적 원리부터 제작, 조종법까지 한눈에 보기

1. 방패연의 핵심 비밀, '방구멍'

방패연 중앙의 동그란 구멍은 바람의 저항을 분산시켜 연이 찢어지거나 뒤집히는 것을 막아줍니다. 강풍 속에서도 자유자재로 당기고 풀며 조종할 수 있는 유일무이한 전통 연입니다.

2. 실패 없는 제작 필수 공식

  • 비율 가로 2 : 세로 3 (예: 가로 40cm, 세로 60cm)
  • 방구멍 가로 길이의 1/3 크기 지름
  • 대나무 살 총 5개 (머릿살, 장살, 대각선 살 2개, 허리살)
  • 핵심 연의 각도를 결정하는 목줄(벌림줄) 밸런스가 제일 중요!

3. 깃허브 웹페이지 구축 노하우

  1. 스마트폰으로 GitHub 접속 후 저장소(Repo) 생성
  2. index.html 파일로 위 코드 저장
  3. Pages 기능을 켜서 나만의 방패연 웹사이트 완성!
